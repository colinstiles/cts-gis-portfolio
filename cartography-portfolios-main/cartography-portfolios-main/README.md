## Background:

For several years I've maintained a private bookmark list of web portfolios featuring maps by working cartographers and artists. The purpose was (is) to keep up with what fellow mapmakers are doing out there and occasionally get a quick jolt of inspiration. Recently, I thought others might find this list helpful, too. I'd also been meaning to explore GitHub Pages; so I made this site to try and knock out two birds with one stone.

Full disclosure, I am not a web developer, and I relied *heavily* on GitHub Copilot to help create this page, tweaking things as needed. It's been a helpful learning exercise for both AI coding (both strengths and limitations) and HTML/JS, but I'm sure there's lots of room for improvement and so am open to helpful suggestions. The goal of the page is to offer a quick and simple path to cartographic goodness via online portfolios. Think StumbleUpon (if you remember that website), but for active mapmakers and map-adjacent designers.

I can guarantee I'm missing many great portfolios out there, probably some from people I know personally that have slipped through the cracks for whatever reason. I see this as an evolving list and intend to maintain it, even if I'm the only one using it. Suggestions for additions are welcome, whether it's your own work or somebody else's. I only ask that they include maps or something map-adjacent, and that preferably there's a page that displays a collection of them. If the portfolio has a specific page for maps, I'd prefer to link to that directly rather than a splash page, an "About Me" page, etc.

Conversely, if someone prefers not to be included, I can remove a site at the owner's request.
