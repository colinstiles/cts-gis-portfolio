# GIS Portfolio

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Personal GIS portfolio site for Colin T. Stiles, hosted on GitHub Pages.

Live site: [colinstiles.github.io/cts-gis-portfolio](https://colinstiles.github.io/cts-gis-portfolio)

## Overview

This repository contains a static portfolio website built with HTML, CSS, and JavaScript. It highlights geospatial work including:

- web maps, dashboards, and StoryMaps
- GIS automation and notebook-based workflows
- cartographic portfolio pieces
- professional background, affiliations, and technical skills

## Project structure

- `index.html` — main portfolio homepage
- `map-gallery.html` — dedicated map gallery page
- `css/styles.css` — site styling
- `js/scripts.js` — navigation, scrolling, menu, and timeline behavior
- `images/` — portfolio images and map gallery assets

## Updating content

Most site content is maintained directly in:

- `index.html`
- `map-gallery.html`
- `css/styles.css`
- `js/scripts.js`

After editing, push to the repository and GitHub Pages will publish the updated site.

## Local preview

Because this is a static site, you can preview it with any simple local web server from the repository root. For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
